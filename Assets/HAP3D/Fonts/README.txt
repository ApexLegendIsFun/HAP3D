Noto Sans KR Regular

HAPFont.ttf is a static weight-400 instance of the upstream Noto Sans KR
variable font, generated using fontTools.varLib.instancer. Static regular
weight keeps the Korean instructions readable in Unity's runtime font renderer.

Upstream: https://github.com/google/fonts/tree/main/ofl/notosanskr
Original font: NotoSansKR[wght].ttf
