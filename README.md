# HAP 3D

이선동의 2차 프로젝트. 기존 HAP의 음양 관계와 중력 반전을 3D 협동 퍼즐로 확장한다.

## Codex에서 이어서 작업하기

Codex에서 이 HAP3D 폴더를 프로젝트로 추가하고 연다. 먼저 AGENTS.md와 Docs의 기획서 원문·작업목록을 읽는다.

다음 시작 요청 예시:

> AGENTS.md와 Docs의 기획 자료를 읽고 HAP 3D 작업을 이어가자. 설치된 Unity 버전을 확인하고, 두 캐릭터 이동·빛블록·중력 반전을 시험할 최소 프로젝트부터 준비해줘. 미정 규칙은 구현 전에 정하자.

## 현재 상태

기획 기반 v0.1과 작업 목록을 준비했다. Unity 안내에 맞춰 진행할 예정이며, Unity 프로젝트와 게임 코드는 아직 생성하지 않았다. 이 저장소의 루트를 앞으로 Unity 프로젝트 루트로 사용할 수 있다.

## 기획 핵심

- 3D, 음·양 두 캐릭터, 로컬 조작, 네트워크 멀티 제외.
- 빛블록: 양 단독이면 길, 음 단독 접근이면 붕괴, 함께하면 안정된 공동의 길.
- 중력 반전, 발판과 행성 내외부, 모션그래픽 참고 비주얼.
- 조작 방식·접근/함께 판정·중력 적용 방식·카메라는 미정.
- 15~25분 및 6~8개 협동 상황은 제안 분량이며 확정 요구사항이 아니다.
