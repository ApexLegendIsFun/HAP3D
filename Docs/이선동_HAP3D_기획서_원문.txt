HAP 3D
2차 프로젝트 기획 원문 v0.6 | 이선동 | 2026.10.13 | 작업명

기획서 PDF v0.4는 학교에 제출한 별도 버전이다. 이 원문 v0.6은 최신 기획이며 제출 완료를 뜻하지 않는다. v0.1.1 최종 13단계 검증, Mac Universal·Windows 64-bit 빌드, Mac 실제 입력 흐름, 두 플랫폼 zip 패키징과 공개를 마쳤다. Windows 실행과 초행 사용자 테스트는 미검증이다.

01. 게임 개요
음과 양의 위치를 맞추며 세 개의 짧은 퍼즐을 함께 풀어 나가는 3D 게임.

게임 소개
HAP 3D는 양과 음 두 캐릭터를 한 명의 플레이어가 번갈아 조작해 빛길을 건너는 3D 퍼즐 게임이다. 양 단독에게 길이 되는 빛블록은 음이 혼자 접근하면 무너지고, 둘이 함께 있으면 안정된 길이 된다. 중력 반전으로 바닥과 천장 사이를 이동한다.

기획 의도
기존 HAP의 음양 관계를 3D 공간의 이동과 협력으로 확장한다. 플레이어가 짧은 퍼즐을 직접 풀면서 빛블록의 관계와 두 캐릭터의 위치 조율을 익히도록 한다.

게임 정보
항목 | 내용
장르 | 3D 퍼즐
플레이 | PC 1인 플레이, 양·음 캐릭터 전환 조작
개발 도구 | Unity / C#
제작자 | 이선동
목표 분량 | 퍼즐 3개, 약 3~5분

플레이의 중심
양과 음을 번갈아 움직이며 함께 길을 건넌다 → 중력을 반전해 다른 바닥으로 이동한다 → 뒤집힌 공간에서도 두 캐릭터가 함께 목표에 도착한다.

02. 핵심 규칙
빛블록은 양과 음의 위치 관계에 반응한다.

빛블록의 세 관계
캐릭터 배치 | 빛블록 반응 | 플레이 결과
양 단독 | 길이 유지된다. | 양이 블록을 밟고 이동할 수 있다.
음 단독 접근 | 블록이 붕괴한다. | 받쳐 주던 길이 사라진다.
양과 음이 함께 | 안정된 길이 된다. | 두 캐릭터가 함께 이동할 수 있다.

조작
PC 한 대에서 한 명이 양과 음을 번갈아 조작한다. WASD로 선택 캐릭터를 이동하고 Tab으로 캐릭터를 전환한다. 게임은 Stage1에서 즉시 시작한다. 화면 왼쪽 위에는 Stage1 / Stage2 / Stage3 표시만 나오며 Stage1에서만 WASD/Tab/G/R 키 그림을 보인다. 키 그림은 누르면 반응하며 WASD·Tab·G·R을 모두 눌러 본 뒤 사라진다. Esc는 종료키로 학습 대상에서 제외한다. Mac 실제 입력으로 해당 키 반응과 숨김을 확인했다. 설명·선택 HUD·제목·완료 패널은 없다. PC 1인 플레이 범위와 이 기본 입력은 승인되었다. 네트워크 멀티와 로컬 2인 동시 조작은 범위에 넣지 않는다.

중간 단계 목표에 도착하면 0.9초 뒤 다음 단계로 자동 이동한다. 마지막 목표에 도착한 뒤 R, Enter 또는 Space를 누르면 처음부터 시작한다. 진행 중 R은 현재 단계를 다시 시작하고 Esc는 종료한다.

중력 반전
중력 반전은 바닥과 천장 사이를 오가는 이동 수단이다. 각 캐릭터의 반전 가능 조건과 세부 동작은 현재 실험 중이며 최종 규칙으로 확정하지 않았다.

실험 중인 빛블록 조건
음 단독 접근 뒤 붕괴까지 0.6초, 두 캐릭터가 판정 범위를 벗어난 뒤 복구까지 2초는 실험값이다. 접근·함께 판정 범위와 안정화 우선순위도 실험 중이다.

03. 세 퍼즐
각 퍼즐은 이전에 배운 빛블록 관계나 중력 반전을 활용해 다른 바닥과 목표에 도달한다. 전체 플레이는 약 3~5분을 목표로 한다.

1단계 — 함께 건너기
두 캐릭터가 빛길을 함께 건너 바닥의 공동 목표에 도착한다. 양 단독 유지, 음 단독 접근 시 붕괴, 함께 있을 때 안정되는 관계를 익힌다.

2단계 — 다른 바닥
영구 발판에서 중력을 반전해 천장으로 올라간 뒤 옆길을 따라 이동한다. 바닥이 달라져도 이동 방향과 다음 발판을 읽는 경험을 만든다.

3단계 — 뒤집혀도 함께
아래쪽 빛다리를 건너 안전 발판에 도착한다. 중력을 반전해 천장 빛다리로 이동한 뒤 두 캐릭터가 공동 목표에 도착한다.

개발 이력 — 초기 실험 구간
초기 실험은 시작 발판 → 빛다리 → 착지 발판 → 천장 목표로 구성된 한 구간이었다. 두 캐릭터의 관계, 중력 반전, 공동 목표를 연결하는 시험용 배치였다. 현재 기획의 세 퍼즐과 구분한다. 현재 세 단계는 별도로 구현하고 자동 검증했다.

04. 공간과 화면 구성
작은 복셀 블록섬에서 세 퍼즐을 진행한다.

비주얼 방향
공간은 작은 블록섬과 간결한 복셀 형태로 구성한다. 양과 음 캐릭터는 흑백으로 구분하고, 빛길은 청록 계열로 표현한다. 블록의 모양과 움직임도 빛블록 상태를 전달하도록 한다.

화면 구성
고정 사선 직교 시점으로 캐릭터, 다음 발판, 목표를 한 화면에서 읽을 수 있게 한다. 이 시점 방향은 승인되었으며 카메라 위치·각도와 프레이밍의 구체값은 실험 중이다. v0.1.1 카메라 2/3 조정을 반영해 13단계 자동 검증을 통과했고 Stage2 천장 아래 캐릭터 얼굴 가림이 없는 것을 확인했다.

후속 공간 구상
모바일 게임의 화면 연출과 공간 표현은 비주얼 참고 자료로 살핀다. 모바일 플랫폼을 현재 목표로 확정하지 않는다. 행성 표면과 내부 공간은 세 퍼즐의 기본 흐름 이후 후속 확장 후보로 둔다. 구면 중력과 행성 내외부 이동은 구현 확정 사항이 아니다.

05. 제작 계획
복셀 형태의 세 퍼즐은 v0.1.0에서 구현했다. v0.1.1 새 글꼴·화면·카메라 자동 검증, 두 플랫폼 빌드, Mac 실제 키 입력 전체 흐름, Mac/Windows zip 패키징 및 공개 프리릴리스 게시를 마쳤다. Windows 실행 및 초행 사용자 테스트는 미검증이며 3~5분 목표도 미확인이다.

현재 진행
승인된 플레이 범위는 PC 1인 캐릭터 전환 조작이다. 세 단계의 공간과 연결, 복셀 외형, 빛블록 상태 표현을 구현했다. v0.1.0에서 13단계 그래픽 자동 검증이 `HAP3D_VALIDATION_OK`로 통과했고 세 단계 모두 제작된 시작 위치에서 검증용 이동 입력으로 목표까지 자동 진행했다. 해당 로그: `/tmp/hap3d-voxel-validation-release.log`. v0.1.1 Nunito 글꼴·화면·카메라를 반영한 최종 setup 및 13/13 검증이 통과했다: `/tmp/hap3d-minimal-ui-setup-final.log` (`HAP3D_SETUP_OK`), `/tmp/hap3d-minimal-ui-validation-final.log` (`HAP3D_VALIDATION_OK`). Mac Universal·Windows 64-bit 빌드 성공: `/tmp/hap3d-minimal-ui-build-mac-final.log`, `/tmp/hap3d-minimal-ui-build-windows-final.log` (`HAP3D_BUILD_OK`). Mac 실제 입력으로 WASD/Tab/G/R 반응 및 모두 입력 후 키캡 숨김, Stage1→2→3 자동 이동, Stage3 마지막 두 목표 완료 후 R로 Stage1 재시작, Esc 종료를 확인했다. Mac/Windows zip 패키징과 공개 프리릴리스 게시를 완료했다. ZIP 크기와 해시는 아래 표에 기록했다. Windows 실행·초행 사용자 테스트는 미실시, 3~5분 목표는 미확인이다.

개발 이력과 제출 상태
학교 제출 PDF는 기획서 v0.4이며, 이 최신 원문 v0.6과는 별도 버전이다. v0.6은 아직 학교 제출 완료로 기록하지 않는다. v0.1.0 source commit `4f56a3b`와 공개 release https://github.com/ApexLegendIsFun/HAP3D/releases/tag/v0.1.0 은 과거 이력이다. v0.1.1 source commit `9ba5f4b0e279991cc7a56e1ec3126a5d2d8bc232`를 원격 main에 push했고 public prerelease https://github.com/ApexLegendIsFun/HAP3D/releases/tag/v0.1.1 를 게시했다. release target SHA는 해당 commit과 일치하며 3개 assets의 업로드 digest가 로컬과 일치했다. 학교 Notion의 Git Repository 항목은 등록 후 다시 읽어 확인했다: https://app.notion.com/p/3e4caf5650aa80309c09fd9cf7c1705a. Windows 실행·초행 사용자 테스트·3~5분 목표 달성은 미검증이다.
