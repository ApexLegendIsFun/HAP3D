Nunito ExtraBold

HAPFont.ttf is a static weight-800 instance of the upstream Nunito variable
font, generated using fontTools.varLib.instancer. The ExtraBold weight gives
the in-game stage marker and keycaps a rounded, clear appearance.

Upstream: https://github.com/google/fonts/tree/main/ofl/nunito
Original font: Nunito[wght].ttf
